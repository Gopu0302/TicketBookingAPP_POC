# Test Cases

Functional test cases generated from acceptance criteria, written as Gherkin feature files.

Each `.feature` file corresponds to one user story, named `<TICKET-KEY>-<short-slug>.feature` (e.g. `KAN-1-search-buses.feature`), and contains one Scenario per testable behavior using Given/When/Then steps.

Generated by the "Test Case Writer" agent (`.github/agents/test-case-writer.agent.md`).
